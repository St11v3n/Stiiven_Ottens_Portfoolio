Õppekogemus

Millega olen siia maani koolis kokku puutunud?

Programmeerimise alused, veebirakenduse loomine, andmebaasi alused (esimene õppeaasta)

  • Programmeerimise alused: Õppisin programmeerimispõhimõtteid Pythoni keeles (Pycharm, Python).
  • Veebirakenduse loomine: Käsitlesin staatilisi ja interaktiivseid veebilehed, samuti ka raamistikke (HTML, CSS, Typescript, Bootstrap, FullStackReact Visual Studio Code, Github Desktop)
  • Andmebaasi alused: Kasutasin SQL andmebaasi tabelite koostmiseks, andmete manupuleerimiseks ning kokku puutusin alustteadmistega (SQL Server Management Studio).

Programmeerimine, tarkvarasüsteemide testimine, mobiilrakendused (teine õppeaasta, kehtib praegult ning ained juurde tulevad)

  • Programmeerimine: Koostasin CRUD rakendused, API kutsed, juurde tuleb veel (C#, Visual Studio, Github Desktop)
  • Tarkvarasüsteemide testimine: Tegin nii backend kui ka frontend teste oma CRUD rakendustele (Visual Studio, C#, xUnit, Github Desktop)
  • Mobiilrakendused: Koostsin erisugused mobiilrakendused, mis puutsid spetsiifilisi funktsioonide kasutamist(Visual Studio, .NET MAUI raamistik, Github Desktop)

Millega tahaks veel tegeleda?

Tahaks ette võtta endale ka mänguarendust, mulle väga meeldivad videomängud ning oleks tore omandada alus teadmised ning neid
tulevikkus rakendada. Olen mänge modifitseerinud, kasutades vahendeid nagu VPKEdit, VTF editor, Blender, Paint.NET, Crowbar
ja VMT editor. Nende vahendite kasutamist ma väga hästi ikkagi ei mõista, kuid sain neid kasutada väikeste asjade jaoks, nagu
animatsioone natuke muutmiseks, tekstuuride muutmiseks, UI elementide koostmiseks mängule ja teiste tehtud modifikatsioonide
muutmiseks. Olen modihaldurit kasutanud, spetsiifiliselt Mod Organizer-it. Kui samuti tahan eelmiste õppeväljundite oskused
veel arendada, sest nad ei ole mul kõige paremini veel meeles jäetud. Kusjuures, tahan rohkem programmeerimis keeltega puutuda
ning nende süntaksi paremini tunda, alusteadmised paremini meelde jätta ning sama ka juba kokku puutunud programmeerimis keeltega ka..

Kokkuvõte

Mul ikka veel palju õppida ning kõik omandatud teadmised ei ole kõik hästi salvestatud mälus, kuid tahan seda muuta ning seetõttu
tahan endale veel juurde kogemust saada nii uute õppeväljunditega kui ka juba läbitud omadega. Teadmiste tõelikku omandamist
võtab aega, seetõttu lähenen sellega rahulikult ning usaldan enda õppevõimekusse.
